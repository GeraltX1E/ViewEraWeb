# ICCH 首页：云端、移动端与工厂现场的概念体验

日期：2026-10-17。范围：首页与所需展示组件；全站产品称谓由“平台 / Platform”统一为“中枢 / Hub”，保留 `/platform` URL。未修改 PLC Studio 桌面、PLC 通信或设备控制代码。

## 理解与参考

升级前首页主视觉为 PLC Studio 镀铜缸总览、温度和电流，容易将一个本地 HMI 实现等同于整个 ICCH 产品。本次将 ICCH 云端与移动端置于前台，PLC Studio 回到工厂工业电脑的现场角色，PLC 负责实际控制与安全联锁。

已读取 Apple Design skill，并在真实浏览器查看 [Apple HomeView](https://www.apple.com/apple-homeview/) 的首屏、多设备视觉及互联章节。借鉴产品先行的大视觉、短文案与章节间留白、场景到特写的节奏；没有复制 Apple 的图片、视频、UI 或品牌资源。采用独立的低饱和矿物绿、原有 ViewEra 标识与系统字体。

## 首页叙事

1. ICCH 登场：云端工厂总览与移动设备自然并置，保留 Control Beyond Boundaries.
2. 家中连接现场：独立绘制的室内抽象场景、手机与工厂视图，支持选择演示工厂。
3. 统一总览：SMT、回流焊、AOI、PCB 测试、包装五条产线，选线联动状态、趋势与工艺详情。
4. 云端到现场：Web/Mobile → ICCH → Internet → 三台工业电脑/PLC Studio → 通用 PLC → PCB 设备。交互聚焦请求、现场校验、执行和反馈四个环节。
5. 请求演示：授权、现场校验、受理、完成与同步；同时展示联锁/离线如何阻止执行。
6. 结束：中枢愿景与产品入口。

## 组件与数据

- `sites/plc-studio/dist/home-copy.js`：首页中英文内容。
- `home-model.js`：纯模拟状态机，无网络、认证凭据或真实控制接口。
- `home.js`：首页显示、跨设备同步、用户事件、动画与计时器生命周期。
- `home.css`：限定在 `.icch-home` 的展示样式，保留其他页设计。
- `app.js`：以现有 Home 路由接入组件并负责切页卸载；`content.js` 与 HTML 元信息更新 Hub 称谓。
- `check.cjs`、`home-check.cjs`：现有路由检查及新增数据/请求/生命周期检查。
- 公共外壳通过 `sync-shells.cjs` 同步五个直接入口，静态部署方式不变。

首帧采用确定性模拟数据：12,480 件、42 台演示设备、4/5 条运行产线、98.6% 良品率、87.4% OEE。数量按产线速率缓慢推进；待机线不增长。概念数据不代表客户或现场结果。

所有云端、移动端与详情视图使用同一个模型。AOI 演示复核仅清除对应工厂的 AOI 提示。切换目标或工厂会取消未完成请求；重置后不会继续完成旧请求。离线时相关指标及无法保证完整性的工厂总数显示“—”。

## 动画与边界

入口使用轻微 transform/opacity 揭示，章节用 IntersectionObserver 随正常滚动出现；不劫持滚动。现场节点按顺序揭示，职责切换保持即时反馈。按钮不因展示动画锁定，只有同一请求处理中禁止重复提交。

模拟每 1800ms 进行一次离散更新，无持续逐帧渲染、视频或 3D 引擎。所有演示区域离屏、页面后台、用户暂停及组件卸载时停止计时器。reduced-motion 显示静态首帧，并保留手动数据/请求步骤；无需等待视频加载。前端无 Google Fonts、Analytics、外部资源 CDN 或设备端连接。

## 实际验证

- 静态服务首页返回 HTTP 200；JS 语法检查与直接入口同步执行。
- 24 种路由/语言/motion 组合通过。
- 10 项纯模型检查通过，覆盖首帧汇总、数量增长、请求顺序、联锁/离线阻断、数据不可用、换目标/重置取消、工厂告警隔离及无传输接口。
- 首页控制器验证播放/暂停、后台、IntersectionObserver 离屏、reduced-motion 与卸载停止。
- 真实浏览器检查 320、390、834、1280px 首页中英文共 8 组，无横向溢出；其他五页中英文共 10 个直接入口通过。
- 实查手机选厂、云/手机/详情选线同步、正常请求五次推进直到回执，以及联锁/离线在现场校验阻断。自动数据推进时所有视图数值一致。
- 实际截图保存在本机忽略目录 `artifacts/home-redesign/`；部署状态以 Sites 工具结果为准。

这是无编译步骤的静态 JS/CSS 网站，无 TypeScript 工程。桌面代码未变，本次未重建 Qt。未进行真实手机硬件、中国大陆网络或真实工业设备验证；操作系统 reduced-motion 未切换，偏好状态与降级行为通过控制器测试验证。
