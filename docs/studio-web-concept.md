# PLC Studio 官网功能概念与仓库拆分

## 本次范围

Products 页的旧镀铜缸演示替换为与首页一致的矿物绿、浅色桌面工作空间。首页叙事、动画与数据模型保持不变。

七个可切换模块为产线总览、工艺流程、数据分析、工艺配方、告警中心、设备连接与操作回执。图表包含班次产量与参考柱状图、质量分布环图、多指标相对趋势、设备活动热力图、周期稳定性散点图、产线参考对比及配方设定条。

以上是用户授权的假设功能展示，不是当前 C++ 桌面软件功能清单。界面集中说明模拟数据和概念模块；三款产品的功能、界面及设备集成可按客户需求与产线设计定制，具体范围按项目确认。

## 交互与边界

- 切换产线、场景、模块、配方预览、告警复核和演示请求均在浏览器内进行。
- 产量柱图各时间段之和与选线总数一致；待机线不增加产量；联锁场景不推进产量。
- 离线场景隐藏实时指标与图表，信号显示未知，不将旧值标记为正常。
- 检测请求按意图、权限、现场校验、受理、完成、回执顺序推进；联锁和离线在受理前停止。
- 更换目标或场景、切页、语言切换取消未完成请求；暂停、后台、离屏、减少动态效果时停止自动推进，减少动态效果支持手动下一帧。
- 没有网络设备接口、寄存器写入、持久化命令或真实控制行为。

## 文件与检查

官网目录中的 `dist/studio.js`、`studio.css` 独立负责演示，`app.js` 复用站点既有计时、弹窗和路由生命周期。`studio-check.cjs` 检查数据一致性、请求顺序、阻止条件、取消和双语模块渲染；`check.cjs` 仍检查七个路由、语言、SEO 和动效生命周期。

## 独立仓库

新的官网权威源码仓库为 https://github.com/GeraltX1E/ViewEraWeb 。网站目录在新仓库根展开，包含 `dist/`、检查和预览脚本、Sites 配置、网站相关文档及设计 Skills（保留上游版权文件）。迁移时保留 Sites 的 project_id、origin 和公开访问属性。

PLCcontroller 内 `sites/plc-studio/` 保留本次迁移快照；后续官网开发在 ViewEraWeb 进行。`src/application/softwareUpdateAgent/web/` 是依赖桌面更新模拟模块的局域网操作页，继续留在 PLCcontroller，不作为独立官网部署。

本次用户已明确授权将 `feat/newWeb` 推送并合并到 `main`，再独立推送官网源码到 ViewEraWeb；不删除原仓库历史。
